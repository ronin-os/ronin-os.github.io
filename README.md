# ronin-os.github.io

Die offizielle Website von [RōninOS](https://github.com/MachuraHarry/RoninOS) – einem freestanding Hobby-Kernel in C.

🌐 **Live:** https://ronin-os.github.io

## Entwicklung

```
git clone https://github.com/ronin-os/ronin-os.github.io.git
cd ronin-os.github.io
# Einfach index.html öffnen oder mit einem lokalen Server:
python3 -m http.server 8000
```
