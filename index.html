Features

Was RōninOS alles kann – kompakt und übersichtlich.

λ

Eigene Shell

Kommando-Parser mit Builtins, Apps, Prompt und Statuszeile. Mit Framebuffer- und VGA-Text-Konsole.

📁

RAM-Dateisystem

Schnelles In-Memory-Dateisystem mit touch, write, cat, cp, mv, rm. Ideal für Tests und temporäre Daten.

💾

FAT32

Eigene FAT32-Implementierung auf generischem Blockdevice-Layer mit format, mount, ls, write, read, delete.

⚡

Preemptives Scheduling

Thread-Erzeugung, Yield, Timer-basiertes Preempting und Prozess-Introspektion via ps, spawn, procmon.

🖥️

Framebuffer-Konsole

Dynamisches Raster aus FB-Größe und Font-Zellgröße. ANSI-Farben, 8×16 Standard-Font, optional 16×32.

🔌

UEFI & BIOS Boot

Multiboot2-kompatibel. Bootet via BIOS-ISO, UEFI-FAT-Image oder partitioniertem USB-Image mit GRUB.

🔍

Diagnose-Tools

Exception-Dumps, Register-Ausgabe, bootinfo, meminfo, disk-Diagnose und manuelle Fault-Tests.

🔗

VFS mit Initrd

Virtuelles Dateisystem mit Root-RAMFS und read-only Initrd-Mount. Multiboot2-Module werden sichtbar.

Architektur

Der Aufbau von RōninOS – sauber getrennt und erweiterbar.

kernel/

  • apps/ – Shell-Applikationen
  • fs/ – Dateisysteme (ramfs, fat32)
  • lib/ – Freestanding-Hilfsbibliothek
  • mem/ – Paging, PMM, Heap
  • sched/ – Thread- & Scheduler-Logik
  • shell/ – Parser, Builtins, Apps
  • terminal/ – VGA/Framebuffer-Terminal

boot/

  • uefi/ – UEFI-Loader & Buildregeln
  • grub/ – GRUB-Konfiguration

tools/

  • scripts/ – QEMU-Hilfsskripte, Docker-Build

Dateisysteme

Zwei Dateisysteme – ein VFS.

RAMFS In-Memory

Das Root-Dateisystem liegt vollständig im RAM. Perfekt für schnelle Experimente.

fs touch test.txt
fs write test.txt "Hello RoninOS"
fs cat test.txt
fs rm test.txt

FAT32 Block Device

Eigene FAT32-Implementierung auf ATA-PIO-Blockdevices mit 8.3-Dateinamen.

fat32 format hd0 --yes
fat32 write NOTE.TXT "Hallo"
fat32 cat NOTE.TXT
fat32 rm NOTE.TXT

VFS + Initrd Virtuell

Einheitliche Schnittstelle: RAMFS als Root, Multiboot2-Module unter /initrd read-only.

ls /
cd /initrd
cat /initrd/banner.txt

Build & Run

      
So startest du RōninOS auf deinem Rechner.

      

        

          
1

          

            
Repository klonen

            
git clone https://github.com/MachuraHarry/RoninOS.git
cd RoninOS

          

        

        

          
2

          

            
Build (BIOS / ISO)

            
make clean && make

          

        

        

          
3

          

            
In QEMU starten

            
make run

          

        

        

          
4

          

            
UEFI-Build & Run

            
make uefi-image
make uefi-run

          

        

        

          
5

          

            
Docker-Build (empfohlen)

            
scripts/build.sh
